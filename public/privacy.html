Privacy Policy - Hawawsheh Store

Last updated: November 2026

Hawawsheh Store operates within the Pi Network ecosystem using the official Pi SDK.

1. Information We Collect

  • Pi Network Account Data: Public User ID (UID) and Username needed for authentication and linking orders.
  • Order & Payment Data: Ordered items, order status, delivery/contact details (if provided for order fulfillment), and transaction/payment IDs to fulfill purchases and handle refunds.
  • Shopping Assistant Queries: Prompts sent to the store assistant to help find products and improve user experience.

2. Security & Non-Collection of Sensitive Credentials

We never collect, store, or request your Pi passphrase, private keys, or sensitive wallet credentials. Authentication and Pi payments occur directly through Pi Network.

3. Data Storage & Sharing

Store and order records are stored in MongoDB for order management, fulfillment, and support. We do not sell user data to third parties.

4. Contact Us

For questions regarding privacy, orders, or data requests, contact us at: ahmadalhawawsha@gmail.com

سياسة الخصوصية - Hawawsheh Store

آخر تحديث: نوفمبر 2026

يعمل متجر Hawawsheh Store ضمن منظومة Pi Network بالاعتماد على واجهة Pi SDK الرسمية.

1. البيانات التي نجمعها

  • بيانات حساب Pi Network: معرّف المستخدم العام (UID) واسم المستخدم (Username) اللازمان لتسجيل الدخول وربط الطلبات.
  • بيانات الطلبات والمدفوعات: تفاصيل المنتجات والطلبات وبيانات التواصل أو التسليم (عند إدخالها لإتمام الطلب) ومعرّفات الدفع لتنفيذ الطلبات ومعالجة طلبات الاسترجاع.
  • استفسارات المساعد: الرسائل المرسلة لمساعد المتجر لتحسين تجربة البحث والخدمة.

2. الأمان وعدم جمع البيانات الحساسة

نحن لا نجمع أو نخزّن أو نطلب مطلقاً العبارة السرية (Passphrase) أو المفاتيح الخاصة أو بيانات المحفظة الحساسة، وتتم المصادقة والدفع عبر Pi Network.

3. التخزين والمشاركة

تُحفظ بيانات الطلبات والمنتجات في قاعدة بيانات MongoDB لإدارة العمليات والتنفيذ والدعم الفني، ولا نقوم ببيع بيانات المستخدمين لأي جهة خارجية.

4. التواصل معنا

لأي استفسارات تتعلق بالخصوصية أو الطلبات أو طلبات البيانات، يمكنكم التواصل معنا عبر البريد الإلكتروني: ahmadalhawawsha@gmail.com
